# Castle Blocks Mod

Add realistic castle blocks to your Minecraft world.

## Features

- Adds a Castle Wall block
- Adds a Castle Tower block
- Adds a Castle Gate block

## Requirements

- Minecraft 1.19.2
- Fabric Loader 0.14.0 or higher

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/castle-blocks-mod/releases).
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric Loader.

## Usage

Once installed, you can find the new blocks in the Building Blocks and Redstone tabs in your creative inventory.

## Configuration

This mod does not have any configuration files. The blocks are added with default settings.
